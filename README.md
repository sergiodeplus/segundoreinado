# Brasil Império · O Segundo Reinado

## Project Goal
Material didático interativo de História voltado para o Ensino Fundamental sobre o Segundo Reinado no Brasil (1840-1889). O projeto inclui textos, ilustrações SVG, um quiz com 20 perguntas e um Mini-RPG text-based ("Uma Vida no Segundo Reinado").

## Tech Stack
- HTML5 (Single File)
- Tailwind CSS (via CDN)
- jsPDF (para geração de certificado)
- Vanilla JavaScript

## Setup / Run Instructions
Basta abrir o arquivo `index.html` em qualquer navegador moderno. O projeto não requer servidor local para rodar.
